# Personal Portfolio — Jeremiah Lillion

My personal portfolio website, built with React and deployed via GitHub Pages.

**Live site:** https://barwolf.github.io

---

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — build tooling
- **Tailwind CSS** — styling
- **Motion** — animations
- **React Router DOM** — client-side routing
- **Lucide React** — icons

## Pages

- `/` — Home
- `/resume` — Resume

## Local Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

The site is deployed to GitHub Pages. Push to `main` to trigger a deployment (if GitHub Actions is configured), or manually deploy the `dist/` folder.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start local dev server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
